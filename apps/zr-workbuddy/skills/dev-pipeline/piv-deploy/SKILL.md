# 部署上线（WorkBuddy 自写）

> Cole 33 清单无 `piv-deploy`，按一体化方案与本仓部署车道定制。

## 何时用
- 一体化第 **10** 步；PR/提交链路已走完（或按配置跳过 PR）

## 输入
- 已配置部署的工程、`workspace`、变更集

## 做什么（完整过程）
1. 走本仓一体部署车道：prepare 变更集  
2. 同步远端 / 按配置重启  
3. 探活；记录 `deploy` job_id  
4. 目录未配置部署 → 诚实失败或跳过（按车道结果，不装成功）  

## 禁止
- 禁止在未配置环境上假装部署成功  
- 禁止跳过探活标准（若配置要求）  
- 禁止改现有部署卡行为（只新开镜像）  

## PASS / FAIL
| | 条件 |
|---|---|
| **PASS** | 部署 Job 成功且探活达标（按车道结果） |
| **FAIL** | 准备失败、同步失败或探活未过 |

## 用户在时间线看到什么
- **Skill**：`piv-deploy · 部署上线`（来源 WorkBuddy 自写）  
- **处理过程**：prepare → 同步 → 探活日志  
- **详细结果**：job_id、探活结论、失败原因
