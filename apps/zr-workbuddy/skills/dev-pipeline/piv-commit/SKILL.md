# 提交 · Git commit/push（改编自 Cole · piv-commit）

## 何时用
- 一体化第 **8** 步；审码已通过

## 输入
- `workspace`、待提交文件、中文说明（可来自需求/PRD；**自动截断 ≤200 字**）

## 做什么（完整过程）
1. 列待提交文件 → 跑提交门禁  
2. 压缩中文 commit message（首行、≤200 字）  
3. 真实 `git commit`（默认可 push）  
4. **最多自动重试 3 次**；仍失败 → **软跳过**本步并继续 9/10，回执带 `can_manual_retry`  
5. 时间线显示「重试提交」；若后续步已完成，手动重试**只跑第 8 步**  

## 禁止
- 禁止因说明过长直接卡死整条流水线（应截断/重试/软跳过）  
- 禁止让模型直接敲 git 绕过车道  

## PASS / FAIL
| | 条件 |
|---|---|
| **PASS** | 提交成功；或无变更跳过；或重试耗尽软跳过（可稍后手动） |
| **FAIL** | 极少：未走软跳过策略时的硬失败 |
