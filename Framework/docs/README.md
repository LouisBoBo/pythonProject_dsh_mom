## 维护约定

1. **新能力**：进 `功能实现/`，并在本索引加一行。  
2. **排障结论**：进 `宿主与运维排障/`，不要只写在聊天里。  
3. **复盘**：`复盘总结/YYYY-MM-DD.md`（北京时间），并在本索引「复盘」表加链接。  
3b. **周报**：`周报/YYYY-MM-DD_YYYY-MM-DD.md`（自然周），并在本索引「周报」表加链接。  
4. **搬家**：改目录后同步改本文件与文内相对链接；根 `README.md` / `AGENTS.md` / `.cursor/rules` 中的 `docs/…` 路径一并改。  
5. **密钥**：只进 `engine/config/config.yaml`（gitignore）；文档只写 `config.example.yaml` 字段名。
