## 为何本机好、服务器翻车

本机 `http://127.0.0.1:3081` 是 loopback：设置镜像、市场 sameOrigin、知识侧栏版本只要装齐就能过。  
公网 `https://\<主机\>:8093/` 同一域名下要同时服务：

- 聊天壳（3081）
- 引擎 API（`/workbuddy/`）
- 公司知识公开 API（`/knowledge-api/`）
- 插件市场（`/dsh-market/`，同源校验）
- remotes 伪装（Host 环回 + 清空 Origin）

**只验本机 = 未交付。**

## 部署动作清单（运维）

1. 代码/引擎按既有 code-deploy；**保留**远端 `trusted_origins`、公司知识配置。  
2. 将仓库 `scripts/deploy/nginx-8093-workbuddy-entry.conf` 同步到线上 8093 vhost → `nginx -t` → reload。  
3. `ensure_dsh_knowledge` / `ensure_runtime` 后检查 cordis：**exposeApi true**、token 仍在；knowledge ≥ 1.0.10。  
4. 重建并部署 `mes-bridge` client（含公网 `/workbuddy` 登录）。  
5. 跑规则 §7 验收表；人工强制刷新公网入口冒烟。
