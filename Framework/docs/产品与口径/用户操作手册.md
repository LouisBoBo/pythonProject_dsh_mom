# 江西中软工作助手 · 用户操作手册

> **写给谁**：要用这个软件干活的同事。不要求会写程序、不要求会开命令行。  
> **写成什么样**：每件事都按屏幕上的字，一步一步写。照着做即可。  
> **对照日期**：2026-10-15。按钮名字以你屏幕上的为准；升级后若个别用词变了，认屏幕上的字。  
> **开发同事另看**：从 SVN 拿代码、改程序、提交源码，读仓库根目录的《使用必看手册》，不要把那份当成产品用法。

桌面安装包的名字是 **MOM**。打开之后，登录页标题是 **江西中软工作助手**。公司如果改过显示名称和 Logo，以登录页上的字为准。

---

## 0. 先记住这几句

1. 日常只开一个入口：自己电脑上的桌面版，或浏览器里的 **http://127.0.0.1:3081**。公司若发了公网地址，那是同一个产品的网页版（常见形式是 `https://公司主机:8093/`）。
2. 聊天、问数、写代码、审代码、提交、部署，都在这一个窗口里完成。改文件、提交、部署之前，屏幕上都会先给你一张确认卡，你点了确认才会真的去做。
3. 聊天要用的大模型钥匙，填在本软件的 **设置 → 商用模型** 里保存。保存成功后，不用再去另一个「设置 → 模型」里填第二遍。
4. 要改哪一个工程，先在左侧 **工作区** 里选中那个文件夹。问数还要在设置里把这个工作区绑到对应的业务系统。
5. 管理员关掉你的某项能力后，对话里会直接拒绝，并提示联系管理员。这不是软件坏了。

## 2. 打开软件并登录

### 2.1 在自己电脑上打开

**桌面版（推荐给要改自己电脑上代码的人）**

1. 双击已安装的 **MOM**（开始菜单或桌面图标）。
2. 先看到启动页，再进入主界面。窗口一出来就应能看见，不要等它自己藏起来。
3. 出现登录挡板后，按下面「怎么登录」填写。

**浏览器版（本机）**

1. 打开浏览器，地址栏输入：`http://127.0.0.1:3081`
2. 出现同一张登录挡板后再登录。

打不开页面时，先确认桌面版已经打开，或请负责安装的同事把本机服务拉起来。不要另找别的端口页面当工作入口。

### 2.2 怎么登录

登录页上有三项：

1. **企业编码**：点开下拉，选你们公司（例如「江西中软」）。这一项是本软件的登录企业，和后面「MES 连接」里填的业务系统账号不是一回事。
2. **账号**：管理员发给你的登录名。
3. **密码**：初始密码或你正在使用的密码。

填完点 **登录**。登录中按钮会变成「登录中…」，成功后挡板消失，进入聊天。

登录失败时，页面会用红字写出原因（账号密码不对、账号已停用等）。把红字原文发给管理员，不要反复猜密码把账号锁住。

### 2.3 忘记密码、被要求改密

聊天窗口里没有「修改我的密码」这一项。

- 忘了密码：请管理员打开 **人员和角色**，在你的那一行点 **重置口令**，设一个至少 8 位的新密码，再告诉你。
- 重置之后，你的状态可能显示 **待改密**。若登录后出现「请先修改默认密码后再继续」，把这句原文发给管理员处理。

### 2.4 退出

1. 点左下角你的头像或账号名，打开账号菜单。
2. 点 **退出登录**。
3. 退出后回到登录挡板。这只退出账号，桌面版的后台还在（见第 21 节）。

## 3. 窗口上有什么

进到主界面后，大致是这几块。名字以屏幕上的字为准。

| 位置 | 是什么 | 你用它做什么 |
|------|--------|----------------|
| 左侧 | 会话列表 | 开新对话、回到以前的对话 |
| 左侧 | **工作区** | 选中当前要问、要改、要部署的工程文件夹 |
| 左侧 | **资料库**、**用量** | 看历史文档、看额度。点开其中一个时，另一个会收起来 |
| 左侧 | **知识库**、**自动化**、**专家** | 装了对应插件后才会出现。和资料库、用量不要叠在一起用：点它们之前，资料库或用量会先收起 |
| 左下角头像 | 账号菜单 | **设置**、**人员和角色**（仅管理员）、**帮助与反馈**、**检查更新**、**退出登录** |
| 中间 | 对话 | 你打字，软件回话；改代码、审代码、提交、部署都会在这里长出一张卡片 |
| 输入框旁边 | **需求→上线** / **普通写码** | 绿色开关。开着走「从需求做到测试环境」，关掉只做普通写码或单独的审、交、部署 |
| 最底下 | 输入框 | 打字、贴图、发送。打开资料库或用量时，输入框仍然留在底部，不会被藏起来 |

发消息：在底部输入框打字，回车或点发送。要附图时，把截图贴进同一条消息。

开新话题：用左侧的新会话。换一件不相干的事时开新会话，避免上一件事的上下文被带进来。

## 4. 第一次让聊天能回话

没有填过大模型钥匙时，聊天可能发了没人回，工具也调不起来。按下面做一次即可。

1. 点左下角账号，点 **设置**。
2. 在设置左侧点 **商用模型**。
3. **提供方** 选一个：
   - **DeepSeek API**：公司发的是 DeepSeek 钥匙时选这个。
   - **Ollama 本地**：钥匙在你自己电脑上的本地模型时选这个。
   - **通用模型配置**：公司发的是别的、但接口和 OpenAI 兼容的钥匙时选这个。
4. 把 **API Key** 粘进去。已经配过的会显示「已配置，留空保存则保持不变」，不要把钥匙再念出来或截图发出去。
5. **Base URL** 和 **模型** 一般保持管理员给的值。没有人给你改过，就先别动。
6. 拉到这一栏底部，点 **保存配置**。成功时会提示已保存。
7. 可以点 **测试 LLM**。通过后再回对话发一句「你好」。

选 DeepSeek 并保存后，钥匙会同步到本机聊天所用的凭据。不要再打开另一处「设置 → 模型」填第二份。

同一页下方还有 **视觉模型**（看截图用），第一次可以先不填。要用贴图时再做第 11 节。

钥匙填错或被清除：再打开 **商用模型**，粘贴新钥匙后保存。要作废旧钥匙，点 **清除 Key**，再保存。

## 5. 选好工作区

工作区就是「现在对着哪一个项目文件夹说话」。

1. 看左侧 **工作区**。
2. 列表里有你的工程，就点中它。
3. 列表是空的：用工作区面板里的添加入口，选你电脑上的项目文件夹（桌面版或本机 3081 才能选你自己的磁盘；公网页不行，见第 22 节）。
4. 选中之后，写码、审码、提交、部署都针对这个文件夹。问数还要在第 7 节把这个工作区绑到对应的业务系统，否则可能问到别的项目的接口。

换项目时，先换工作区，再开新会话提问。软件会按当前文件夹认识这个项目（用的什么技术、目录怎么摆）。你若有额外约定（例如「菜单配置在某个文件里」），告诉管理员写进该工程的项目说明，避免软件沿用上一个仓库的习惯。

## 6. 用中文问数

用来查产量、良率、OEE、缺陷、工单、在制品，以及已经导入的只读接口（保养计划、仓储等）。不要用它改代码。

**事先要具备**

- 你的账号开着「问数」（管理员默认全开）。
- 第 7 节已经把业务系统地址和接口文档配好，并且绑了当前工作区。
- 第 4 节的模型已经保存成功。

**做法**

1. 确认左侧工作区是你要查的那个工程。
2. 输入框旁的绿色开关保持 **普通写码**（关掉「需求→上线」）。问数不需要打开这条流水线。
3. 直接用中文问，例如：
   - 「今日在制品工单有多少个」
   - 「查今日在制品工单明细」
   - 「查询设备保养计划」
4. 等回复。问「多少、汇总、对比」时，给你合计；问「明细、列表、计划」时，给你记录列表（一次最多大约 50 条），需要时带图表。
5. 没问清楚就在同一条会话里接着问，例如「只要 A 车间的」。换一个完全不同的主题时，开一条新会话，免得把「工单」理解成上一句里的保养工单。

**问不到数时**

- 回复说联系管理员开通：你的「问数」被关掉了。
- 回复说采购单价或员工工资尚未接入、或你没有权限：这两项是敏感数据，默认不给普通成员。其它产量、工单不受影响。
- 回复说没有接口或连不上：回到第 7 节检查地址、账号和文档是否已保存，工作区是否绑对。

也可以在对话里说「测一下连接」或「看连接状态」，让软件自检业务系统和模型是否通。

## 7. 接上业务系统

一个项目一张对接卡。卡上同时放：业务系统地址、登录信息、接口文档、绑定的工作区。问数只打你绑到当前工作区的那张卡。

1. 账号菜单 → **设置** → **MES 连接**。
2. 已有卡片就点进要编辑的那一张（标题会带「当前编辑」）。没有就点右上角 **＋**（新增对接卡）。
3. **绑定工作区**：下拉列表和左侧工作区是同一份。先在左侧加好工程，这里才能选到。选中后应显示「已绑定：……」。
4. 填写 **MES 连接**：
   - **Base URL**：业务系统地址，向业务管理员要。
   - **账号**、**密码**、**企业编码**：登录那个业务系统用的，不是第 2 节登录本软件用的。
5. 导入接口文档（三个方式选一个）：
   - **上传文件**：Swagger / OpenAPI 的 json 或 yaml，或含接口列表的 Markdown。
   - **从 URL**：填文档地址。需要账号时再填用户名和密码。
   - **粘贴原文**：把 OpenAPI 原文，或 Markdown 里的 `GET /api/…` 列表贴进去。
6. 先看预览，确认接口列表对，再点本页底部 **保存配置**。
7. 回到已绑定的那个工作区，用第 6 节的问法试一句。

页面提示「尚未接入接口」时，就是文档还没保存成功。提示「暂无可用工作区」时，先回左侧把工程加进工作区。

多工厂、多项目：每个项目一张卡，各自绑自己的工作区。不要把两个厂的地址写在同一张卡上。

删错卡：在卡片上点删除。删除前确认这张卡不是别人正在用的项目。

## 8. 问 PCB 工艺

用来问工艺流程、叠层、阻抗、DFM、检测、IPC 术语、缺陷可能出在哪道工序。它不查 MES 产量。

1. 账号需要开着「PCB工艺」（默认开着）。
2. 在对话里直接问，例如：「这个开路缺陷一般对应哪道工序」。
3. 问题里写清现象、工序或标准名，回答会更准。

这和问数是两条路。问「今天产出多少」走第 6 节；问「这种缺陷算哪道工序」走本节。

## 9. 普通写码（只改代码）

用来改页面、改菜单、加一个功能、按截图改界面。人点确认之后才会改你电脑上的文件。不会自动提交，也不会部署。

**事先要具备**

- 账号开着「写码」。
- 第 18 节已安装并处于运行中的 **Cursor 对话写码**。没装这个插件时，对话不会改你的工程。
- 第 4 节模型已保存。写码若还要单独的公共模型钥匙，按第 20.4 节填写。
- 左侧工作区已选中要改的工程。
- 用桌面版或本机 3081。公网页改的是服务器上的目录，不是你眼前这台电脑（第 22 节）。

**做法**

1. 看输入框旁边。应显示 **普通写码**。如果显示绿色的 **需求→上线**，点一下关掉。
2. 用一句人话说明要改什么。有界面截图就贴在同一条消息里。例子：「把订单列表页的导出按钮挪到表格右上角，样式跟筛选按钮一致。」
3. 对话里会出现写码卡片，标题类似「写码确认 · 核对后再开工」。
4. 在卡片里核对工程目录、原始诉求和软件整理出来的摘要。
5. 勾选「我已核对原始诉求与目标模块，确认摘要不偏离业务目标」。
6. 点 **确认并用 Cursor 写入本机**（或卡片上同等含义的确认按钮）。没点之前，文件不会被改。
7. 看同一条对话里的进度。做完后，到工程里看改动是否符合你的原话。
8. 不对就在同一会话里补充一句，例如「按钮颜色改回蓝色」。这是继续改，不是提交。

卡片若提示本会话已开「需求→上线」、不会弹出写码确认卡：说明绿开关还开着。要只改代码，先关掉开关，再发一次需求。

写码成功后，本次真正改过并已同步的源码会进资料库。没改到的文件不会进。

## 10. 需求到上线

把「一句话或一张图」走完一条流水线：理解需求、看项目、出方案、改代码、检查、复核、提交、能开合并请求就开、最后部署到测试环境。它调用的仍是第 9、12、13、14 节那些能力，不会另做一套。

**事先要具备**

- 账号开着「需求到上线」，同时写码、审码、提交、部署也开着（默认都开）。
- 第 9 节的对话写码插件已安装。
- 要部署成功，工程里还得有第 14 节的部署规则，并且目标是测试或预发，不是生产。
- 贴了截图的，第 11 节的视觉模型要先配好。

**做法**

1. 选好工作区。
2. 点输入框旁的开关，直到显示 **需求→上线**。这个开关只对当前会话有效。
3. 发文字，或贴界面截图，或文字和截图一起发。例子：「按这张图，给保养计划列表加一个按设备编号筛选。」
4. 对话里出现一张过程流卡片，徽章是 **需求→上线**。进度画在这张卡上，不要到别的窗口去找。
5. 步骤名称按顺序是：

   | 顺序 | 卡片上的名字 | 这一步在做什么 |
   |------|----------------|----------------|
   | 1 | 需求采集 | 收下你的原文；开了绿开关时，会把附图一起读进去 |
   | 2 | 需求理解 | 整理成可以动手的说明 |
   | 3 | 读库上下文 | 看当前工程的结构和相关文件 |
   | 4 | 规划实现 | 打算改哪些地方、怎么算做完 |
   | 5 | 写代码（Cursor 插件） | 真正改文件。时间线上这一格可能只写「写代码」 |
   | 6 | 验证 | 按项目里配置的检查命令跑，只认过或不过 |
   | 7 | 复核 | 只看这次改动，相当于自动做一次审码 |
   | 8 | 提交 | 把这次改动提交到版本库 |
   | 9 | 开 PR | 开合并请求。工程是 SVN 时，这一步会标成不适用 |
   | 10 | 部署上线 | 部署到测试或预发，不是生产环境 |

6. 多数步骤会自己往下走。卡片出现 **待你确认**，或写着「本步需你确认后才能继续」时，先读内容，再在卡片上确认。没确认就不会改盘、不会提交、不会部署。
7. 要停下来：点卡片上的停止，或在输入框发送「暂停」或「取消」。
8. 需求说错了：再发一条更正。软件会新开一轮，并带上本会话上一轮的上下文。

**怎样算没做成**

- 写码跑完但一个业务文件都没改：软件会打回去重做，最多 3 轮。3 轮后仍没有改动，就停住，不会假装提交成功。
- 验证没过：流水线停在验证，不会带着错误去提交。
- 工程里没有部署规则，或探活失败：部署不算成功。看第 14 节。

绿开关关掉时，同一句话只走第 9 节的普通写码，不会进这条流水线。

## 11. 看图

截图、界面照片要先被「看懂」，再交给写码或需求流水线。

1. 账号菜单 → **设置** → **商用模型**。
2. 拉到 **视觉模型**。
3. 点一个快速填入：**智谱 GLM-4V**、**Qwen-VL** 或 **自定义**。
4. 填视觉用的 API Key、地址和模型名。提示「请自行填写视觉模型 Base URL 与模型名称」时，选「自定义」后这两项都要写。
5. 点页面底部 **保存配置**。
6. 回到对话，把图片贴在消息里。

用法分两种：

- 开着 **需求→上线** 时贴图：采集那一步会自动带上这张图。
- 普通写码时贴图：由对话写码自己看图，你只要把图和改动说明放在同一条消息里。
- 只想让它描述图片：在对话里明确说「看一下这张图」，并贴上图片。

没配视觉模型就贴图，会提示未就绪或无法生成视觉说明。先做完上面 1～5 步。

## 12. 审代码

对你选中的本机工程做审查，出风险说明。它直接读源码，不依赖你有没有先提交。审查不会改文件。

1. 账号开着「审码」。输入框旁保持 **普通写码**（绿开关关掉）。
2. 在对话里说「审核这段代码」或「看看这次改动」。
3. 主聊天里出现审码卡片（就在对话中，不是单独弹窗）。
4. 选工程目录。当前工作区一般已经填好，不对就改。
5. 点 **下一步：选文件**。
6. 勾选要审的文件，可选填 **审查重点**。
7. 点 **开始审核所选**。若你不想逐个勾，点 **不选文件·默认抽样**。
8. 等审查结果出现在卡片上。需要看以前的报告时，按卡片或回复里的报告号再问，或到第 15 节资料库里打开。

选错目录：点 **返回改目录**，再来一遍。提示「请至少勾选一个文件」时，要么勾文件，要么改点默认抽样。

## 13. 提交代码

把你勾选的文件提交到本机 Git。可以选择一并推送到远端。软件不会在你没点确认时自己执行提交。提交前有一道检查，不过关就不会提交。

1. 账号开着「提交」。绿开关关掉。
2. 工作区选的仓库里确实有改动。
3. 在对话里说「提交代码」。
4. 卡片上选目录，点 **下一步：选文件**。
5. 勾选要提交的文件。不要勾密钥、本地配置、别人的无关改动。
6. 填写 **中文提交说明**。空着不能继续。
7. 看检查结果。通过后才会出现确认。
8. 要推到远端，就点 **确认提交并推送**。只留在本机，就点 **确认仅本地提交**。
9. 看结果：
   - 「已提交并推送到远程」：本地和远端都完成。
   - 「已本地提交（未推送）」：只在你电脑上。
   - 「本地已提交，推送未完成」：提交已经在，推送失败。可以说「重试推送」，或在卡片上点 **重试推送**。不要为了推送再提交一次，以免造成重复提交。

检查没过：按卡片上的原因改。有时会再给你一张写码卡，让你先修好再提交。没有待提交文件时，卡片会说明工作区是干净的，这时不要硬交。

工程使用 SVN 时，提交走仓库自己的方式；「开合并请求」那一步对 SVN 不适用。日常口头说「提交代码」，仍以卡片上的按钮为准。

## 14. 部署

把当前工程同步到测试或预发，并检查服务是否还活着。你点 **确认部署** 之后才会开始。生产环境名会被拒绝。服务检查失败时会把文件退回去，不会把「文件传上去了但网站挂了」当成成功。

设置页里已经没有「自动化部署」总开关。规则写在**要部署的那个工程里面**，不写在本软件的设置里。

### 14.1 工程里要有的两个文件

在工程根目录（选中的工作区那一层）建立文件夹 `.workbuddy`，里面两个文件：

**`.workbuddy/deploy.yaml`**（可以提交给团队，里面不要写私钥）

把下面换成你们环境的真实值。主机、目录、探活地址向负责服务器的同事要。

```yaml
version: 1
preset: vite_backend
build_where: local
build_cmd: "npm run build"
build_cwd: frontend
sync_paths:
  - frontend/dist
  - backend
ssh:
  host: "服务器地址"
  user: "登录用户"
  port: 22
  app_path: "/服务器上的项目目录"
entry_url: "http://服务器上的业务入口/"
health_url: ""
default_ref: HEAD
```

`preset` 按项目类型选：前端加后端常见是 `vite_backend`；只有静态页面用 `static`；说不清就先问负责部署的同事，不要留空碰运气。

**`.workbuddy/deploy.local.yaml`**（只留在你电脑上，不要提交）

```yaml
ssh:
  key_path: "~/.ssh/你的私钥文件名"
```

私钥必须放在你的用户主目录下（例如 `C:\Users\你的名字\.ssh\`）。不要把私钥正文贴进任何一个 yaml。可提交的 `deploy.yaml` 里禁止出现私钥路径、密码、Token。

探活地址（`entry_url` 或 `health_url`）要能打开。没有可检查的地址时，这次部署不会被记成成功。

### 14.2 在对话里部署

1. 账号开着「部署」。左侧工作区就是这个工程。
2. 绿开关关掉（单独部署时不要开「需求→上线」；走流水线时由第 10 步自己调用部署）。
3. 说「部署到预发」或「部署上线」。不要说部署到生产。
4. 卡片标题是 **确认增量部署** 或 **确认全量部署**。看清环境（应是 staging 一类测试环境）、同步范围、要更新的单元。
5. 点 **确认部署**。按钮变成「部署中…」时等待，不要连点。
6. 成功时标题类似「增量部署完成」或「全量部署完成」。失败时读红字。若写明已回滚，说明新版本把服务搞挂了、文件已经退回，网站应仍是上一版；这次部署仍然算失败，需要改完再部署一次。

卡片写「部署未就绪」或提示补 `.workbuddy/deploy.yaml`：回到 14.1，文件要放在当前工作区根上，不是放在子文件夹里。

## 16. 用量

用来看大模型对话和 Cursor 写码各用了多少。合计等于：没命中缓存的输入 + 输出 + 缓存读写。推理用的额度只出现在明细里，不加进合计。数字按上海时间的自然日计算。公司控制台网页上的数字可能比这里晚一会儿，以这里的账本为当天对照，过一会儿再对控制台。

1. 点左侧 **用量**。
2. 默认是 **个人用量**。
3. 选日期。统计粒度选 **按日** 时，下面是各时段；选 **按月** 时，日期变成月份，下面是各日。
4. 页面上分「LLM」和「Cursor 写码」两块。没有调用时显示「暂无调用」。

管理员还可以点 **企业用量**：

- 看全员合计，以及按人从高到低的用量（含管理员自己）。
- 非管理员点企业用量会提示「仅管理员可查看企业用量」。

企业汇总若未由管理员打开上报，企业页可能没有公司合计。这不影响你看自己的个人用量。

## 17. 知识库

知识库和资料库不是同一个东西。

| | 资料库 | 知识库 |
|--|--------|--------|
| 放什么 | 某次审码、写码、会话留下的文档 | 制度、工艺、笔记，用来在聊天里被引用 |
| 入口 | 左侧 **资料库** | 左侧 **知识库**（装了知识库插件才有） |
| 左侧「已分享」 | 不是这个 | 「已分享」是笔记分享，不是公司共享知识库 |

**本手册已预置在本机「默认知识库」。** 打开应用就会有，不必自己上传，也不必做「项目与会话挂载」。任意会话里直接问「手册里怎么……」即可；侧栏打开知识库 → 默认知识库，也能看到《江西中软工作助手 · 用户操作手册》。

公司共享库是全公司同一份。本机知识库只在你这台电脑上，别人看不到。

**普通成员**

1. 左侧打开 **知识库**。
2. 上传文档时没有「公司共享」选项，文件只进本机库。
3. 可以阅读侧栏里的 **公司共享知识库**（只读，带「共享 / 免挂载」一类标记）。不能在公司库里新建、导入或删除。
4. 在聊天里问制度、工艺时，软件只能引用管理员勾给你的那些公司文档。没勾的文档不会出现在回答里。

**管理员**

1. 上传或导入时必须选目标，没有默认悄悄进公司库这一说：
   - **本机知识库**：只有这台电脑能用，适合草稿和敏感未定稿。
   - **公司共享知识库**：全员可按权限检索。选它时按提示再确认一次。成功后应看到已对公司可见一类提示。
2. 管理员可以在公司共享库侧栏新建、导入、删除。删除会同步去掉中央库里的那一篇。
3. 谁能在聊天里引用哪一篇公司文档：到第 19 节，点该成员的 **能力**，在共享知识库勾选里调整，再点 **保存知识库权限**。默认是全选。本机知识库不受这些勾选影响。

侧栏只有「默认知识库」、没有「公司共享知识库」时，把现象告诉管理员，不要把它理解成资料库丢了。

## 19. 人员和角色（管理员）

只有角色是管理员的账号，左下角菜单里才有 **人员和角色**。成员看不到这一项。

打开后可以：新增、停用、改角色、重置口令，以及按人开关功能、敏感数据和公司文档。至少留一名未停用的管理员。勾选不会立刻生效，要点对应的保存按钮。

### 19.1 新增一个人

1. 点 **新增人员**。
2. **账号**：字母开头，例如 `zhangsan`。
3. **显示名**：可选，方便在列表里认人。
4. **初始密码**：至少 8 位。
5. **角色**：选 **成员** 或 **管理员**。日常干活的人选成员。
6. 点 **保存**。把账号和初始密码单独告诉对方，不要发到大群。

### 19.2 改角色、停用、重置口令

在该人那一行：

- **改为成员** / **改为管理员**：立刻切换角色。
- **停用**：该账号不能再登录。停用后可以再点 **启用**。
- **重置口令**：填写至少 8 位的新密码，点 **确认重置**，再私下告诉对方。对方状态可能变为 **待改密**。

### 19.3 功能开关

点该人的 **能力**。功能默认全开。关掉某一项后，这个人在对话里就不能用它，并会看到联系管理员的提示。全局如果把某个功能插件停掉，则所有人都不能用，不受这里勾选影响。

可单独开关的有：

| 名称 | 关掉之后 |
|------|----------|
| 问数 | 不能查产量、工单等 |
| PCB工艺 | 不能做工艺问答 |
| 写码（Cursor 对话写码） | 不能改工程 |
| 审码 | 不能发起审查 |
| 提交 | 不能提交 |
| 部署 | 不能部署 |
| 需求到上线 | 不能开绿色流水线 |
| 视觉识图 | 不能走识图 |
| 连接配置 | 不能做连接类自检 |

改完点 **保存能力**。只勾不保存，旁边会提示未保存。

### 19.4 敏感数据

同一能力面板里还有数据权限，默认不给成员：

- **物料采购单价**
- **员工工资**

勾选后点 **保存数据权限**，这个人问数时才可能看到对应数字。没接入的项，问出来会说明尚未接入，不影响产量和工单。

### 19.5 公司文档能被谁引用

仍在这个人的能力面板里，勾选允许聊天召回的公司共享文档，点 **保存知识库权限**。没勾的文档，回答里不会出现原文。默认全选。这里不管本机私人笔记。

## 20. 其它设置

都从左下角账号菜单进入 **设置**。除「应用配置」自己有保存按钮外，其余分页改完后点该页底部 **保存配置**。

### 20.1 应用配置（名称和 Logo）

1. 点 **应用配置**。
2. 要启用你们自己的名字和图标，勾选 **启用自定义配置**。
3. **上传 Logo**：png、jpeg 或 svg。
4. 填 **应用名称**、**应用概览**。
5. 点 **保存并启用**（勾了启用时）或 **保存配置**。
6. 刷新页面后，登录页和界面上的名称、图标才会换成新的。取消勾选再保存，则回到内置默认。

### 20.2 自动化推送

点 **自动化推送**。企业微信群机器人和飞书多维表格是两套，可以只开一个。

**企业微信**

1. 填写 **群机器人 Webhook**（完整地址，或地址里 `key=` 后面的那段）。
2. 打开企微推送开关。
3. 保存。之后任务在勾了「推送到企业微信」并且成功时，才会发到这个群。联调模式不会真的呼叫企微。

**飞书多维表格**

1. 填飞书应用的 App ID、App Secret。
2. 勾选 **开启飞书多维表格同步**。
3. 保存。具体任务还要打开「同步到飞书多维表格」，并填好表格的 app_token 和 table_id，只开总开关不会写表。

### 20.3 远端审码

点 **远端审码**。用于飞书 Webhook 触发后，调用本机审码并把结果写回飞书。

填写飞书 App ID、App Secret，以及可选的 Webhook 密钥，然后 **保存配置**。这些内容留在本机，不要写进业务仓库。

### 20.4 公共模型

点 **公共模型**。这里的 API Key 保存后会同步给对话写码。对话写码提示缺少钥匙时，填这里，再点 **保存配置**。已经配过的钥匙留空保存，表示不修改。

### 20.5 帮助与反馈

1. 账号菜单 → **帮助与反馈**。
2. 在输入框里写下问题或建议。
3. 需要附图时点添加图片。点缩略图可预览，点移除可删掉某张。
4. 提交。不要在反馈里粘贴 API Key、密码或私钥。

## 21. 桌面版的开关和升级

**关窗口不等于退出。** 点窗口关闭后，程序进系统托盘，后台还在，下次打开更快。

- 要回到窗口：点托盘图标，选 **打开**（菜单文字带产品名）。
- 要彻底停掉：托盘里选 **退出**。只关窗口时，再点一次桌面图标应只出现一个窗口。

**升级**

1. 账号菜单 → **检查更新**。桌面版每天第一次打开也会自己查一次。
2. 没有更新时，会告诉你当前已是最新版本。这是正常结果，不是故障。
3. 有新版本时，左下角可能出现「发现新版本」提醒。点升级进入更新面板；也可以点关闭提醒，稍后再到 **检查更新**。
4. 看清版本号后，由你确认再下载、再安装。安装向导拉起时，本软件会退出，按安装程序的提示做完。
5. Windows 上若提示应用仍在运行、无法关闭：先用托盘 **退出**，不要在任务管理器里结束所有 python。然后再安装。

浏览器打开的 3081 没有桌面安装包可升。版本以你安装的 MOM 为准。

## 22. 在公网页上用

公司发给你的公网地址（常见是 `https://主机:8093/`）和本机 3081 是同一个产品：登录、聊天、知识库、插件市场、设置都从这一个网址进去。

和在自己电脑上打开的差别：

1. **选文件夹只能选服务器上的目录**，不能弹出你电脑的资源管理器。页面上会标明工程目录在服务器。
2. 要改你自己电脑里的代码、审你自己电脑上的仓库、提交你自己的本地改动：请安装桌面版 MOM，或在自己电脑打开 `http://127.0.0.1:3081`。
3. 登录失败若出现一整段看不懂的 `not found` 文字，把原文发给管理员，不要改用别的网址试。
4. 设置里的插件市场更新若提示来源不受信任，或「设置 → 模型」提示当前浏览器不可用：这是公网站点配置问题，把原文发给管理员。本软件的钥匙仍然以第 4 节 **商用模型** 为准。

| 登录红字 | 核对企编、账号、密码；停用账号找管理员点启用 |
| 发出去没有回复 | 做第 4 节，保存商用模型钥匙后再试「你好」 |
| 提示联系管理员开通 | 第 19.3 节里对应功能被关掉了 |
| 问数没有业务数据 | 做第 7 节：地址、文档、工作区绑定、保存配置 |
| 问到了别的项目的数 | 左侧工作区和 MES 卡片绑定的不是同一个工程 |
| 说了改代码但文件没变 | 绿开关是否误开；对话写码插件是否「运行中」；是否在确认卡上点了确认 |
| 开着需求→上线却没有写码确认卡 | 这是正常的，进度在过程流卡片上 |
| 写码成功但没有文件变化，然后停了 | 最多重做 3 轮。把需求说得更具体，或换一张更清晰的截图再发 |
| 审码要求 path 或重新列文件 | 在卡片上重新选目录，再点「下一步：选文件」 |
| 提交说工作区干净 | 工程里没有未提交的改动，先确认你改的是当前工作区 |
| 本地已提交、推送失败 | 点「重试推送」，不要再提交一遍 |
| 部署未就绪 | 在工程根补 `.workbuddy/deploy.yaml` 和只留本机的 `deploy.local.yaml` |
| 部署失败且已回滚 | 网站应仍是旧版。按报错改配置或代码后再部署 |
| 说部署到生产被拒绝 | 只部署测试或预发 |
| 贴图没被看懂 | 做第 11 节并保存视觉模型 |
| 资料库或用量突然要重新登录 | 刷新一次。仍要求登录就重新登录。不要同时开着多个入口抢同一个账号实验 |
| 插件市场没有公司插件 | 告诉管理员，不要改市场地址 |
| 侧栏没有公司共享知识库 | 告诉管理员核对知识库插件版本和公司库是否已接入 |
| 公网页不能选我电脑上的文件夹 | 改用桌面版或本机 3081 |
| 关了窗口以为退出了 | 看托盘。要停干净须点托盘「退出」 |

## 24. 不要做的事

- 不要把 API Key、密码、私钥发到聊天、反馈或群里。
- 不要在可提交的 `deploy.yaml` 里写私钥路径或私钥正文。
- 不要在没点确认卡时以为代码已经改了、已经提交或已经上线。
- 不要把生产环境当作部署目标。
- 不要把左侧「已分享」当成公司共享知识库。
- 不要为了用聊天，再去另一个「设置 → 模型」填第二把钥匙。
- 开发同事不要按本手册去改仓库；改程序请看《使用必看手册》和 `Framework/docs/README.md`。
