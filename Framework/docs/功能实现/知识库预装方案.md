# 知识库预装（@zhongruan/dsh-knowledge）

> **状态**：WorkBuddy 预装已切到中软包（2026-09-16）  
> **一句话**：不自研 RAG；出厂预装 **`@zhongruan/dsh-knowledge`**（独立插件仓 fork lemoncat7 并加上传后发布）。  
> **边界**：资料库（`space/`，会话产物）≠ 知识库。  
> **公司共享库**：产品定稿见 [共享知识库方案.md](./共享知识库方案.md)（中央 `exposeApi`；成员只写本机；管理员上传选本机或公司；读公司 P0 旁路）；本篇只负责预装接线。  
> **插件开发**：见 [中软知识库插件-上传文档开发指导.md](./中软知识库插件-上传文档开发指导.md)

## 风险与缓释

| 风险 | 缓释 |
|---|---|
| 与 `dsh` 版本耦合（回写要 `snapshotEvents`，约需 0.1.2-rc.1+） | 默认 `extractionEnabled: false`，演示只做召回问答 |
| 用户 patch 覆盖 `knowledge` 整块时冲掉 `databasePath` | 预装块必须带齐 `backend` / `databasePath` / `connectionPath` |
| 与 lemoncat7 / `dsh-knowledge-base` 双开 | ensure 从 dependencies/bundles **移除**遗留包 |
| 中软包尚未发布到公司 npm | `dsh plugin add` 失败会提示；**未装上前不写入依赖、不卸 lemoncat7**，避免拖垮 bridge `pnpm install` |
| 架构误塞进 `features/` | 仍走 DSH profile Cordis 包；本仓只做脚本预装 |
| **市场装卸其它线上插件** → pnpm prune 剪掉 `mammoth` 等 peer → 宿主崩、3081 白屏 | ① `pnpm-workspace` 写入 `minimumReleaseAgeExclude`（`@zhongruan/*` + `dshmarket`），避免卸包踩 resolution-policy；② 托管 pack + profile **双份 hoist** 关键 peer；③ `ensure_runtime` 必查 `knowledge_peers`，缺则**拒绝启动** |

## 版本策略（托管 link · 不定死源码版号）

| 项 | 默认 |
|---|---|
| 包名 | `@zhongruan/dsh-knowledge` |
| 版本 | 运行时取公司 npm `dist-tags.latest` |
| 落盘 | `$DSH_HOME/workbuddy-packs/dsh-knowledge` |
| profile 依赖 | `link:../../workbuddy-packs/dsh-knowledge`（躲开 pnpm 旧锁打回） |
| 调试钉版 | 仅设 `WORKBUDDY_KB_VERSION=x.y.z` |

环境变量：

- `WORKBUDDY_KB_PKG`（少用）
- `WORKBUDDY_KB_VERSION`（可选；不设则解析公司 npm latest）

## 怎么触发预装

- 开发：`scripts/host.sh wire` 或 `restart-web`  
- 装 bridge：`scripts/plugin.sh --app zr-workbuddy install bridge`  
- 桌面一体包：启动接线 `ensureWorkBuddyWire`  

实现：[`scripts/lib/ensure_dsh_knowledge.py`](../../scripts/lib/ensure_dsh_knowledge.py)

## 用户怎么用（产品口径）

1. 打开 WorkBuddy 聊天壳，侧栏「知识库」  
2. 固定「知识问答」工作区，在「项目与会话挂载」挂上库  
3. 用中软包 **导入文件**（或过渡期新建粘贴）后提问  
4. 默认关回写；宿主升到兼容版本再开  

### 本机预置《用户操作手册》（免上传 · 免挂载）

- 源文件：`apps/zr-workbuddy/config/builtin-knowledge/用户操作手册.md`（与 `Framework/docs/产品与口径/用户操作手册.md` 同步）  
- 启动时 `ensure_local_user_manual` / 引擎 soft-seed 写入 `$DSH_HOME/knowledge/knowledge.sqlite` 的 **默认知识库**（`id=default`）  
- 同时落盘 `$DSH_HOME/knowledge/builtin/用户操作手册.md`  
- 聊天免挂载召回：工具 `mes_workbuddy_manual`（feature `workbuddy-manual`）+ systemPrompt；侧栏默认库可见同名文档  
- 实现：`scripts/lib/ensure_local_user_manual.py`、`engine/app/builtin_manual.py`  

## 明确不做

- 不把生态包焊进 `mes-bridge` / `features/`  
- 不在本仓改知识库插件源码  
- 不自研切分/向量库（等私有化 API）  
- 不与 `@lemoncat7/dsh-knowledge` 长期双开  

上传能力在 **独立插件仓** 完成：见 [中软知识库插件-上传文档开发指导.md](./中软知识库插件-上传文档开发指导.md)。
